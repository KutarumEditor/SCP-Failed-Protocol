# SCP: FAILED PROTOCOL                      

SCP: Failed Protocol is a Garry's Mod total SCP Breach revision.

Each round SCP's are trying to break out, Class-D and Scientists are trying to escape,
Security with MTF are trying to stabilize the situation and multiple organizations are trying to make their own business.
